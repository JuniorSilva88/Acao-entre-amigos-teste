# 🤝 Ação Entre Amigos – 5ª Edição  

**Ação Beneficente – Iluminando o Futuro**  

🔗 Link: [https://iluminandofuturos.com.br/](https://iluminandofuturos.com.br/)

---

## 📝 Descrição em **PORTUGUÊS - BR**  

Este é o site da **5ª edição da Ação Entre Amigos – Iluminando o Futuro**, uma iniciativa voltada para ajudar crianças de comunidades em Curitiba, especialmente durante o Natal. O site foi desenvolvido utilizando **HTML, CSS e JavaScript**, com integração ao **Netlify Forms** para receber doações e mensagens.  

### Seções do Site:
- **Sobre a Ação:** Explica os objetivos e a importância da campanha.  
- **Galeria:** Exibe fotos e registros das edições anteriores.  
- **Doações:** Fornece QR Code e chave Pix para doações financeiras.  
- **Solicitar Coleta:** Botão que direciona para o formulário de contato.  
- **Parceiros:** Apresenta os apoiadores da iniciativa.  
- **Contato:** Formulário integrado ao Netlify para envio de mensagens.

O estilo do site foi projetado para ser simples, acolhedor e responsivo.

## 📝 Description in **ENGLISH**  

This is the website for the **5th Friends Action – Lighting the Future**, a charity initiative focused on helping children in Curitiba communities, especially during Christmas. The site was built using **HTML, CSS, and JavaScript**, with **Netlify Forms** integration for donations and contact messages.  

### Website Sections:
- **About the Action:** Explains the goals and importance of the campaign.  
- **Gallery:** Displays photos and records from previous editions.  
- **Donations:** Provides QR Code and Pix key for financial donations.  
- **Request Pickup:** Button that scrolls to the contact form.  
- **Partners:** Shows the initiative’s supporters.  
- **Contact:** Netlify-integrated form for sending messages.
